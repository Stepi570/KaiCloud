Инструкция по использованию KaiCloud

1. Получение ID

  1. Откройте Telegram и найдите бота @kit_raspisanie_bot
  2. Нажмите кнопку Cloud в меню бота
  3. Вы получите сообщение с вашим уникальным ID
  4. Скопируйте этот ID

2. Аутентификация на сайте

  1. Введите скопированный ID в поле на этой странице
  2. Нажмите кнопку Начать

3. Загрузка файлов

  1. Перетащить файлы в обозначенную область
  2. Или нажать Выбрать из локальных для выбора файлов через диалог
  3. Файлы будут автоматически отправлены в ваш Telegram-аккаунт

4. Важные моменты

⚠️ Обратите внимание:

  • Ваш ID действует 10 минут с момента получения
  • Если ID истек, вернитесь в Telegram и получите новый
  • Максимальный размер файла: 20 MB

5. Техническая поддержка

Если у вас возникли проблемы:

  1. Напишите в Telegram-бот @kit_raspisanie_bot
  2. Выберите пункт Обратная связь
  3. Опишите вашу проблему
